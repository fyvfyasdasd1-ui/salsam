# salsam

Простой калькулятор с красивым GUI.

## Запуск

Откройте `index.html` в браузере.

## Возможности

- Базовые арифметические операции: `+`, `−`, `×`, `÷`
- Процент, смена знака, сброс (AC)
- Поддержка клавиатуры (цифры, операторы, `Enter`, `Esc`, `Backspace`)
- Адаптивный glassmorphism-интерфейс с анимированным градиентом
