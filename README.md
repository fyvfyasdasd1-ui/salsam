# Salsam 2.1 — центр настройки Windows

C# / .NET 8 / WPF, MVVM. Тёмный интерфейс с панелью состояния, профилями, каталогом оптимизаций и мониторингом. Каждое изменение сначала попадает в очередь: его можно исключить галочкой. Перед применением показывается подтверждение. Прирост FPS не обещается.

## Запуск без установки

Готовый файл: `artifacts/portable-x64/Salsam.exe`. Скопируйте **только этот EXE** на компьютер с Windows 10/11 x64 и запустите двойным щелчком. .NET, Visual Studio, DLL рядом с EXE и подключение к Интернету для запуска не нужны. ARM64 и 32-битная Windows этой сборкой не поддерживаются.

При первом запуске встроенные библиотеки распакуются в пользовательский TEMP; запуск может занять несколько секунд. Папки TEMP и LOCALAPPDATA должны быть доступны для записи. Оптимизации применяются после выбора и подтверждения. EXE не подписан цифровой подписью. Запуск автономного EXE, переход в «Мониторинг» и показ измеренных CPU/RAM проверены автоматическим прогоном на Windows-раннере GitHub Actions.

## Архитектура

- `src/Salsam.Core`: журнал с атомарной заменой файла, сохранение исходного значения перед изменением, чтение результата, откат с проверкой внешних изменений, расчёт метрик времени кадра.
- `src/Salsam.App`: WPF, MainViewModel, команды и привязки. WindowsBackend отделён от представления через ISettingBackend; использует штатные powercfg, HKCU Run и PowerShell/CIM. MonitorService использует Windows API.
- `tests/Salsam.Checks`: исполняемые проверки ядра без сторонних пакетов.
- `tests/Salsam.WindowsChecks`: проверки настоящего HKCU Run, карантина, визуальных настроек и датчиков. Создают собственные временные данные и убирают их в finally; существующие записи автозагрузки не меняются.

## Сборка и запуск на Windows 10/11

Установите .NET 8 SDK из официального источника Microsoft. В Visual Studio нужна нагрузка «Разработка классических приложений .NET», но сама Visual Studio необязательна. Выполните из корня репозитория:

```powershell
dotnet build src/Salsam.App/Salsam.App.csproj -c Release
dotnet run --project src/Salsam.App -c Release
dotnet run --project tests/Salsam.Checks -c Release
dotnet run --project tests/Salsam.WindowsChecks -c Release
```

Приложение запускается обычным пользователем (asInvoker). Если политика запрещает действие, показывается ошибка; автоматического повышения прав нет. Windows-проверки выполняйте при закрытом приложении.

Сборка единого автономного EXE Windows x64:

```powershell
dotnet publish src/Salsam.App/Salsam.App.csproj -p:PublishProfile=Portable -o artifacts/portable-x64
```

Запускайте `artifacts/portable-x64/Salsam.exe`. Профиль Portable включает runtime, управляемые и native-библиотеки в файл, не использует trimming и не требует соседних файлов. Исходные проекты и тесты для разработки по-прежнему требуют SDK.

## Возможности и ограничения

| Возможность | Реализация |
| --- | --- |
| Оборудование | CPU, GPU и версия драйвера GPU, RAM, диски и Windows через CIM |
| Питание | Существующие схемы и семь параметров активной схемы: USB, PCIe, простой диска, сон, экран, минимальное и максимальное состояние CPU. Меняются только значения для питания от сети; параметры батареи сохраняются |
| Профили | «Сбалансированный»: существующая сбалансированная схема + семь анимаций включены. «Игры»: существующая высокая производительность + семь анимаций, ускорение и след мыши выключены. Недоступные действия исключаются. Пользовательский профиль сохраняется локально и загружается в очередь |
| Каталог | Чтение текущего состояния, поиск, фильтр категории, выбор каждого изменения. 37 настроек: 17 параметров интерфейса, 4 параметра ввода, 8 предпочтений Проводника, выбор схемы и 7 параметров питания от сети. SystemParametersInfo, SHGetSetSettings и powercfg; проверка применения и откат |
| Анализ | Считывает оборудование, питание, настройки, автозагрузку и временные файлы. Показывает число уже установленных и доступных для выбора значений без выдуманного рейтинга быстродействия |
| Автозагрузка | HKCU Run текущего пользователя, описание и издатель из метаданных exe, отключение выбранной записи и восстановление строки и типа |
| Очистка | Просмотр файлов верхнего уровня пользовательского TEMP старше 7 дней, перенос выбранных в карантин, восстановление без перезаписи конфликтующих файлов |
| Мониторинг | CPU, RAM, наиболее занятый отдельный GPU 3D-счётчик, суммарное чтение/запись физических дисков, питание от электросети/батареи. Сбор счётчиков в фоне; недоступность и прогрев обозначены явно |
| Измерения | Импорт CSV времени кадра, средний FPS, 1% low и графики до/после на общей шкале |
| Восстановление | Журнал, отдельный откат, откат всех в обратном порядке, проверка наличия точек Windows |

Журнал и карантин: `%LOCALAPPDATA%\Salsam`. Не удаляйте папку, если нужен откат. Второй экземпляр в пользовательском сеансе блокируется. Ошибка прекращает последующие операции; выполненные остаются в журнале. При конфликте с внешним изменением откат отменяется.

Игровой режим и фоновая запись открываются в штатных настройках; их состояние автоматически не определяется. Ручные изменения Windows в журнал не попадают. Управление сторонними оверлеями, температура, захват FPS в реальном времени и создание точек восстановления не реализованы — интерфейс явно это показывает. GPU — максимум отдельного 3D-счётчика процесса/движка, не общий процент загрузки адаптера; диски — скорость передачи в МиБ/с, не процент занятости.

Карантин на том же диске **не освобождает место**; необратимое удаление не реализовано. Очистка не обходит подкаталоги TEMP, личные документы, сохранения и кэши шейдеров. Заблокированные файлы принудительно не удаляются. Defender, обновления, брандмауэр, службы, HPET, таймеры, сетевой стек и «очистка RAM» не затрагиваются.

## Проверка фактического состояния

Карточки показывают состояние, прочитанное из Windows, отдельно от предлагаемого действия: «Включено», «Уже выключено», «Уже настроено» или «Недоступно» с причиной. Настройку, которая уже совпадает с целью, повторно выбирать нельзя; противоположное действие доступно в раскрытом описании. Ошибка чтения не считается отключённой функцией.

Состояние повторно читается непосредственно перед применением. Совпадение пропускается без системной записи и без лишней записи в журнале. После записи проверяется результат; журнал хранит точное наблюдаемое значение для проверки конфликтов при откате. Изменение ускорения мыши сохраняет её пороги; значения следа указателя 0 и 1 распознаются как отключение, но исходное число сохраняется для восстановления.

«Рекомендованные» добавляет ограниченный набор изменений интерфейса и показ расширений файлов; каждый пункт можно исключить. Другие параметры, включая доступность мыши, USB и энергопотребление, выбираются вручную. Ни количество настроек, ни их состояние не являются оценкой производительности. Microsoft рекомендует сохранять выборочную приостановку USB включённой; соответствующий пункт предназначен для диагностики конкретных устройств.

Параметры питания относятся к конкретной активной схеме. Нельзя одновременно применить её параметры и перейти на другую: сначала выберите схему, обновите состояния, затем измените параметры. Недоступные параметры не получают выдуманных значений. Возврат к исходным значениям использует журнал, а не предполагаемые «заводские» значения.

## CSV

CSV с разделителем `,` или `;`, BOM и стандартными кавычками (включая разделители внутри полей). Заголовок FrameTimeMs или MsBetweenPresents; положительные конечные миллисекунды с десятичной точкой. Минимум 100 кадров **одного процесса**. Экспортируйте отдельно нужную игру и исключите строки инициализации с нулевым временем. Если присутствует ProcessID / ProcessId, смешение процессов отклоняется. Без столбца идентификатора экспорт одного процесса остаётся обязанностью пользователя.

FPS = 1000 / среднее время кадра. 1% low = 1000 / среднее время самых медленных 1% кадров, число округляется вверх. На графике длинные записи группируются с сохранением максимума группы. Сравнивайте одинаковые сцену, настройки, разрешение, прогрев и длительность; импорт не доказывает причинную связь с оптимизацией.

## Проверка на Windows

1. Проверьте оборудование и изменения CPU/RAM под нагрузкой.
2. Добавьте другую доступную схему. Исключите её галочкой: применение недоступно. Включите, подтвердите и проверьте powercfg /getactivescheme. Выполните откат и проверьте снова.
3. Запустите WindowsChecks для проверки автозагрузки и карантина на собственных тестовых данных.
4. Импортируйте реальные CSV одной игры; проверьте обе линии и отсутствие показателей до импорта.
5. Проверьте окно при 100%, 150%, 200% DPI, поиск, навигацию, прокрутку и отказ в операциях при ограничивающей политике.

## Облачная среда

В Linux успешно собрана WPF Release-версия с Windows targeting; проверки ядра, профилей, CSV и фактических состояний прошли. В Linux окно не запускалось. Отдельный Windows-прогон исходного кода 13c6a18 успешно выполнил проверки ядра, системных настроек и отката, сборку и запуск единого EXE, UI Automation-переход в «Мониторинг» и проверку измерений CPU/RAM. Проверка собственного компьютера при разных DPI и политике доступа остаётся полезной.

SDK: `/workspace/.dotnet`. Для команд задайте DOTNET_CLI_HOME=/workspace/.dotnet-cli и NUGET_PACKAGES=/workspace/.nuget/packages, чтобы не писать в недоступный домашний каталог. Linux поддерживает редактирование, сборку и проверки ядра; GUI требует Windows.


## Автоматическая проверка Windows

`.github/workflows/windows.yml` запускается при изменении кода в ветке salsam-download: проверки ядра, настоящих настроек и их возврата, автономная сборка и UI Automation smoke. `scripts/Smoke-Portable.ps1` запускает именно единый EXE, переключает разделы и проверяет показ измеренных CPU/RAM. Если нет рабочего интерактивного рабочего стола, проверка завершается ошибкой и не выдаёт отсутствие доступа за успешный тест.

Предыдущая версия 2.0.1 прошла [Windows-прогон](https://github.com/fyvfyasdasd1-ui/salsam/actions/runs/37693352068). Нативные проверки и GUI smoke завершились успешно; необязательные GPU-счётчики зависят от драйвера. Это проверка на Windows-раннере, а не на каждом сочетании оборудования и настроек пользователя. Для локальной проверки на Windows:

```powershell
./scripts/Smoke-Portable.ps1 -ExePath artifacts/portable-x64/Salsam.exe
```
