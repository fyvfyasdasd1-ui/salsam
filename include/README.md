# ScriptHookV SDK headers go here

Download the ScriptHookV SDK zip from <http://www.dev-c.com/gtav/scripthookv/>
and extract its `inc/` folder so the layout becomes:

```
include/
  inc/
    enums.h
    main.h
    natives.h
    nativeCaller.h
    types.h
```

The SDK is not redistributed in this repo because it has its own license
attached to Alexander Blade's distribution. Grab it directly from his site.
